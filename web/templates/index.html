ascii-tile-demos

__COUNT__ demos of tiled overland map rendering — square, isometric, and hex — drawn entirely in a grid of styled characters with retroglyph and hexal. The same Rust source runs in a terminal, in a native window, and here in your browser.

Software is the CPU rasterizer drawing to a <canvas>; WebGL2 is the GPU backend running the same instanced-quad renderer the native OpenGL 3.3 build uses. They should look identical — that is the point. Drag to pan, and see each card for the keys it responds to.
